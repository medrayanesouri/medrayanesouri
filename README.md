## 🚀 Selected work

### Weather Forecast Correction — DGM Internship

During my July–August 2026 internship at Morocco's Direction Générale de la Météorologie, I extended a two-station prototype into an operational forecast correction pipeline on Linux HPC.

- Prepared data and trained **64 Random Forest models across 32 stations** for minimum and maximum temperatures.
- Corrected temporal data leakage using chronological splits and implemented a fallback to AROME forecasts when model improvement was insufficient.
- Reduced pooled **Tmax RMSE from 3.01°C to 2.83°C (about 6%)** in July 2026 evaluation using observations from **33 stations**, including AROME fallbacks.
- Automated **two daily runs** with Bash and Cron and built a map dashboard comparing forecasts and observations.

**Tools:** Python, pandas, NumPy, scikit-learn, Linux HPC, Bash, Cron, Leaflet, Chart.js.

### [Real-Time Object Detection & Tracking](https://github.com/medrayanesouri/pfa-emsi-detection)

Built a webcam and file analysis application with **YOLOv8m**, **ByteTrack**, and a React/FastAPI interface.

- Collected and annotated **1,099 images across five classes**: EMSI logos, people, backpacks, pens, and phones.
- Integrated CPU inference through **OpenVINO**, with approximately **20–35 ms per image on an Intel i9-13900H**.
- Connected webcam inference through WebSocket and supported file analysis.

**Tools:** Python, YOLOv8m, OpenVINO, ByteTrack, FastAPI, WebSocket, React.

### [Learning Path Architect](https://github.com/medrayanesouri/learning-path-architect)

Built a personalised learning application covering learner profiling, adaptive quizzes, curriculum generation, and tutoring.

- Orchestrated application state and conditional workflow transitions with **LangGraph**.
- Added **RAG** over PDFs, web sources, and Wikipedia using **LangChain** and **ChromaDB**.
- Integrated local **llama3.1:8b** inference through **Ollama**, a **FastAPI** backend, and **SQLite** persistence.

**Tools:** Python, LangGraph, LangChain, ChromaDB, Ollama, FastAPI, SQLite, React.
